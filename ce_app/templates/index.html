Help & Documentation
Quick reference for using FillForge.

📦 What is FillForge?

FillForge is Jumbotail's internal catalog automation portal. It reads raw seller dump files (Excel) and auto-populates the master PV template — applying title formatting, color merging, size expansion, set-detail parsing, HSN/GST mapping and duplicate detection in one click.

🚀 How to create a catalog file

1. Select a category from the top bar (Footwear or Consumer Electronics). 2. Upload the seller dump file (required). 3. Optionally upload Base Data for duplicate-SKU detection. 4. The system auto-detects product verticals from the dump — confirm or change the selection. 5. Click Generate Catalogue File. 6. Preview the filled rows and download the .xlsx (or .zip if multiple SubTypes were selected).

👟 Footwear

Supports all footwear PV SubTypes (Men's, Women's, Boys', Girls', Infant's). Auto-derives gender from SubType, merges primary & secondary colors, expands size ranges, builds set details, and maps HSN/GST. Set count is parsed from the dump's Quantity or Set Of column. Multi-SubType runs produce a ZIP of separate .xlsx files.

📱 Consumer Electronics

CE supports 20 product verticals across Mobile (Feature Phones, Smart Phones), Mobile Accessories (Adapters & Cables, Cases & Covers, Headsets, Memory Cards, Mobile Cables, Mobile Holders, Screen Guards, Power Banks, Smart Watches, Speakers), Audio & Video (Earphones, Neck Bands, Microphones, Projectors, Soundbars, TWS Ear Buds, Webcams), and Personal Care (Hair Trimmers). It auto-detects the input Product Type, fetches the matching schema from the CE - PV Template sheet using the CE - Mapping Logic sheet, extracts model names from titles, pulls display type / charging type / bluetooth / processor info from product descriptions, and handles RAM+ROM combo formatting. Set count is always 1 (individual units). Configure brands and defaults in CE Settings.

⚙ Settings & Multi-Brand

Configure multiple brands with their IDs in Settings. The system reads the Brand column from your dump file and auto-maps the correct brand & ID for each row. Add as many brands as needed — e.g., Samsung → BR-123, Redmi → BR-456. If no match is found, the first configured brand is used as fallback.

🗂 Download Templates

Go to Download Templates from the sidebar. Footwear (full master or per-SubType blank) and Consumer Electronics templates are available.

🔒 Coming Soon

Apparels & Fashion, Toys & Sports, and Home Furnishing modules are currently under development and will be available in a future release.
