Help & Documentation
Quick reference for using FillForge.

📦 What is FillForge?

FillForge is Jumbotail's internal catalog automation portal. It reads raw seller dump files (Excel) and auto-populates the master PV template — applying title formatting, color merging, size expansion, set-detail parsing, HSN/GST mapping and duplicate detection in one click.

🚀 How to create a catalog file

1. Upload the seller dump file (required). 2. Optionally upload Base Data for duplicate-SKU detection. 3. The system auto-detects product verticals from the dump — confirm or change the selection. 4. Click Generate Catalogue File. 5. Preview the filled rows and download the .xlsx (or .zip if multiple SubTypes were selected).

⚙ Settings

Brand details, business category, default GST split and listing constants live in Settings. These are applied to every row of every generated file until changed.

🗂 Download Templates

Need the blank master template? Go to Download Templates from the sidebar. Only Footwear is enabled in v0.3 Beta; the other categories are queued for upcoming releases.

🔒 Login & Security

Access is via email OTP. Codes expire in 5 minutes. Every login, generation and download is logged with the user's email for audit purposes — see Activity Logs.

🆘 Need more help?

Reach out to the Catalog Ops team or raise a ticket with the dump file + error message. Most generation failures come from missing required columns in the dump or unrecognised Product Vertical names.
