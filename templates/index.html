Help & Documentation
Quick reference for using FillForge.

📦 What is FillForge?

FillForge is Jumbotail's internal catalog automation portal. It reads raw seller dump files (Excel) and auto-populates the master PV template — applying title formatting, color merging, size expansion, set-detail parsing, HSN/GST mapping and duplicate detection in one click.

🚀 How to create a catalog file

1. Select a category from the top bar (Footwear, Consumer Electronics, or Apparels & Fashion). 2. Upload the seller dump file (required). 3. Optionally upload Base Data for duplicate-SKU detection. 4. The system auto-detects product verticals from the dump — confirm or change the selection. 5. Click Generate Catalogue File. 6. Preview the filled rows and download the .xlsx (or .zip if multiple SubTypes/categories were selected).

👖 Apparels & Fashion

Apparel processing generates 5 files per category: JPIN, TaxMaster, SCM (Supply Chain), ProductAttributeValue, and L4. Supports Jeans, Shirts, T-Shirts, Track Pants, Cargo & Sarees with per-PV dynamic PAV templates. Auto-detects PV from *Industry Product Sub-type column. Mandatory columns are highlighted green and auto-filled with # if empty. Set composition is automatically calculated from quantity and size columns. Configure brands and per-PV settings in Apparel Settings.

📱 Consumer Electronics

CE supports Feature Phone and Smart Phone verticals. It extracts model names from titles, pulls display type / charging type / bluetooth / processor info from product descriptions, and handles RAM+ROM combo formatting. Set count is always 1 (individual units).

⚙ Settings & Multi-Brand

Configure multiple brands with their IDs in Settings. The system reads the Brand column from your dump file and auto-maps the correct brand & ID for each row. Add as many brands as needed — e.g., Samsung → BR-123, Redmi → BR-456. If no match is found, the first configured brand is used as fallback.

🗂 Download Templates

Need the blank master template? Go to Download Templates from the sidebar. Footwear, Consumer Electronics, and Apparels & Fashion are available in v0.5 Beta.

🆘 Need more help?

Reach out to the Catalog Ops team or raise a ticket with the dump file + error message. Most generation failures come from missing required columns in the dump or unrecognised Product Vertical names.
